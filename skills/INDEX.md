# Workspace Skills Index

Status: canonical workspace entry point for shared agent skills.

This folder is the source of truth for skills that apply across multiple projects in this workspace.

## Responsibilities

- Host the master index for shared agent skills.
- Separate workspace-global skills from project-local `CLAUDE.md` guidance.
- Provide stable categories for domain, platform, product, delivery, governance, template, recipe, and migration content.
- Track the migration of legacy skill content from `Skills library/`.
- Maintain `CREDITS.md` as the consolidated external-source attribution registry — every skill citing an external source should have a matching row there.

## Category Model

- `domains/`: domain-specific skills aligned with DDD bounded contexts (e.g. payments, pricing).
- `platform/`: shared engineering and runtime skills for monorepo, tooling, testing, and infrastructure.
- `engineering/`: cross-project coding standards, architecture patterns, testing strategies, and software development practices.
- `product/`: product overlays that are shared within a product family but do not belong in a single project-local `CLAUDE.md`.
- `management/`: management-practice skills grounded in W. Edwards Deming's work — diagnosing management practice, policy, and variation, distinct from `strategy/` (what to pursue) and `refinement/` (what to schedule).
- `delivery/`: planning, decomposition, QA, release, and workflow execution guidance.
- `governance/`: standards, security controls, compliance (e.g. PCI DSS, zero-trust delegation), monitoring, and policy-oriented guidance.
- `templates/`: canonical authoring templates for new skills, recipes, and compliance chunks.
- `recipes/`: reusable procedure-style instructions with strong implementation guidance.
- `communication/`: structuring and delivering written communications (reports, memos, RFCs, briefings).
- `financial-impact-analysis/`: cost/margin/ROI modeling — the cost-based pricing floor beneath `strategy/`'s demand-side pricing ceiling.
- `migrations/`: move maps and migration notes from legacy locations.
